# Filtros Digitales en Python
Este repositorio contiene el código en Python para el diseño y análisis de filtros digitales (Pasa Bajos, Pasa Altos y Pasa Bandas) utilizando `scipy` y `matplotlib`.

## Funcionalidades
- Generación de una señal compuesta con ruido blanco.
- Implementación de filtros IIR Butterworth.
- Análisis visual de señales filtradas mediante `filtfilt` (filtrado de fase cero).

## Requisitos
- Python 3.x
- NumPy
- SciPy
- Matplotlib
